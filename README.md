# PROJECT ROY — Off the Grid

סימולטור חיים **on-chain rogue-lite** בהשראת *"Roy: A Life Well Lived"* (ריק ומורטי, עונה 2 פרק 2)
ובהשראת מבנה הריצה של [Legionnaire](https://www.legionnaire.xyz/).

חיים שלמים בעשר דקות. ריצה אחת, permadeath, וציון שנצרב כ־Soulbound.

---

## הרצה

אין תלויות ואין שלב build — זה אתר סטטי עם ES modules, אז צריך רק שרת מקומי:

```bash
npx http-server -p 8080      # או: python3 -m http.server 8080
# → http://localhost:8080
```

## מה יש כאן

```
index.html            כל המסכים
styles.css            ערכת ארקייד־טרמינל, RTL, mobile-first
src/                  מנוע המשחק (9 מודולים, אפס תלויות)
contracts/RoyRun.sol  חוזה ייחוס ל־Base/Arbitrum
docs/GDD.md           מסמך האפיון המלא
```

## המכניקות בקצרה

- **שני מסלולים** — `MORTY` (Safe Yield: חנות שטיחים, ביטוח, שרידות גבוהה, מכפיל נמוך)
  מול `RICK` (Degen: שריפת ה־SSN, חיים מחוץ לרשת, permadeath אמיתי, מכפיל ×1.6 ומעלה).
- **ארבעה משאבים** — בריאות, שפיות, קריירה, הון. אחד מהם מתאפס והריצה נגמרת.
- **תדירות החלטות** — פרק / 2 / 3. מה שלא בוחרים, מנוע ה־RNG פותר לבד ומציג כ־FAST-FORWARD.
- **משברים כפויים** — האבחנה בגיל 30, קריסת השוק, חוב, מרדף. אפשר לשרוף פריט כדי לשרוד.
- **תודעת נחיל** — במצב `ROY 2: DAVE` שנים־עשר שברי תודעה מצביעים איתך; הרוב קובע.
- **מורשת** — ה־Roy ID נשרף בסיום, הריצה נצרבת כ־Soulbound, והתכונה החזקה עוברת `+1` לדור הבא.
- **האוסף שלי** — 22 הישגים קבועים ששורדים את ה־permadeath.

## Provably fair

כל הגרלה נגזרת דטרמיניסטית מ־`seed ‖ chapter ‖ salt` (xmur3 + sfc32).
אותו seed מייצר בדיוק את אותה ריצה, וה־receipt של כל הטלה מוצג ב־on-chain log.

## שכבת הבלוקצ'יין

בפרוטוטייפ הכל רץ מול `MockChainAdapter` (`src/chain.js`) שנשמר ב־localStorage:
ארנק, `$TICKET`, טרנזקציות, מאגר פרסים, Soulbound ולוח תוצאות.
הממשק זהה לזה שיחובר ל־provider אמיתי; `contracts/RoyRun.sol` מגדיר את הצד השני.

## קובץ יחיד להרצה בנייד

```bash
node build-standalone.mjs
```

יוצר שני קבצים ב־`dist/`, שניהם עצמאיים לחלוטין — CSS, JS ושני הפונטים מוטמעים כ־base64,
בלי אף בקשת רשת בזמן ריצה (עובד גם offline וגם מ־`file://`):

- **`standalone.html`** — מסמך שלם. אפשר לפתוח ישירות מהדפדפן, לשלוח בוואטסאפ, או להעלות לכל שרת סטטי.
- **`embed.html`** — גרסת body בלבד, למארחים שמספקים `<head>` משלהם (RTL מגיע מ־CSS במקום מ־`dir`).
